# FleaHelper_SPT_5.0
Плагин быстрой продажи предметов на барахолке

## Возможности
***Продажа одной кнопкой*** — выделите предмет в инвентаре, нажмите горячую клавишу — предмет автоматически выставится на барахолку по цене из справочника (Handbook)
Переключение валюты — рубли, доллары или евро. Переключается на лету отдельной клавишей, без перезахода в меню
Внутриигровые уведомления — после выставления лота показывает всплывающее уведомление с названием предмета, ценой и валютой
Локализация — названия предметов отображаются на языке вашей игры (русский, английский и др.) благодаря прямому чтению файлов локализации сервера SPT
Обход лимитов — опциональная настройка для игнорирования ограничений на количество активных лотов

## Установка
Убедитесь, что установлен BepInEx 6.0.0-be.788+ (IL2CPP) и SPT 5.0
Скопируйте FleaHelper.dll в папку BepInEx/plugins/
Запустите игру — плагин создаст конфигурацию при первом запуске

## Настройка
Все настройки доступны в файле BepInEx/config/com.zzzNIKOzzz.fleahelper.cfg или через Configuration Manager (F12 в игре):

## Использование
- Откройте инвентарь
- Наведите курсор на предмет
- Нажмите горячую клавишу (по умолчанию **LeftControl**) — предмет выставится на барахолку
- В правом нижнем углу появится уведомление: «Лот создан: (Имя предмета) по цене (Цена предмета)»

## Технические детали
Вся работа с игровыми типами — через IL2CPP-рефлексию (без прямых ссылок на сборки EFT)
Локализация читается напрямую из SPT_Data/database/locales/global/ru.json — работает для любого языка сервера
Совместимость с Il2CppReferenceArray<T>, Il2CppStringArray, DelegateSupport.ConvertDelegate
Поддержка MongoID — 24-символьные hex-идентификаторы EFT
